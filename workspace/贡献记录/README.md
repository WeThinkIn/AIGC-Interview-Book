# 共创贡献记录

贡献记录是月度贡献者榜单和季度趋势报告的基础台账。这里只登记已经合并、已经采纳或经过维护者确认的贡献，不把未核验投稿直接当作事实样本。

## 记录范围

- 已合并的 Pull Request；
- 已采纳并转化为仓库内容的 Issue；
- 对事实校验、隐私去敏和内容重构产生关键作用的协作贡献；
- 被纳入季度报告样本，但因隐私原因不公开原文的去敏贡献。

## 记录字段

| 字段 | 说明 |
| --- | --- |
| 日期 | 合并或确认采纳日期 |
| 贡献者 | GitHub 用户名或经本人确认的公开署名 |
| 共创方向 | 七类共创方向之一 |
| 成果 | Issue、PR、章节、路线或报告链接 |
| 角色 | 投稿、整理、校验、维护 |
| 质量说明 | 这项贡献为什么具有准确性、时效性或复用价值 |
| 样本权限 | 可公开、仅统计、不可进入趋势分析 |

## 维护流程

1. Issue 或 PR 被采纳后，由维护者登记到当年记录。
2. 月末核对贡献者署名、成果链接、贡献角色和样本权限。
3. 月榜只引用已经确认的记录，并补充贡献亮点，不按提交次数机械排序。
4. 季报建立独立样本快照，排除重复、无法核验和超出时效范围的内容。

当前记录入口：[2026 年共创记录](2026年共创记录.md)。新年度开始时复制 [贡献记录模板](贡献记录模板.md)，按 `YYYY年共创记录.md` 命名。
