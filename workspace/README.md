# AIGC-Interview-Book 社区共创工作区

这里是《三年面试五年模拟》的社区共创控制台。它负责把个人学习路线、真实面经、公司题库、岗位信息和技术观察，转化为可校验、可署名、可持续维护的公共知识资产。

共创的核心不是增加文件数量，而是建立一条稳定链路：

> 真实经历与一手信息 → 结构化投稿 → 社区校验 → 主仓库沉淀 → 贡献记录 → 月度榜单 → 季度趋势报告

## 共创工作流

1. **确定问题**：先说明这次贡献服务哪类人、解决什么问题，以及为什么值得进入公共知识库。
2. **选择模板**：通过 Issue 表单快速提交，或使用离线模板完成较长内容的整理。
3. **补齐证据**：标明时间、版本、来源边界与不确定性；技术内容优先引用论文、官方文档、源码和模型卡。
4. **完成去敏**：删除候选人、面试官、内部业务、联系方式和受保密协议约束的信息。
5. **社区校验**：围绕准确性、完整度、时效性、复用价值和表达质量讨论修订。
6. **合并归档**：通过审核的内容进入主仓库，并登记到贡献记录台账。
7. **形成反馈**：高质量贡献进入月度贡献者榜单，并成为季度趋势报告的候选样本。

详细标准见 [共创提交规范](共创提交规范.md) 和本目录的 [贡献指南](CONTRIBUTING.md)。

## 共创身份

- **共创贡献者**：至少有一项内容被主仓库采纳并登记。
- **高质量贡献者**：在一个自然月内形成具有明显准确性、完整度或复用价值的贡献。
- **专题共建伙伴**：围绕同一公司、岗位或技术方向持续贡献并协助校验。
- **方向维护者**：长期维护专题内容、回应相关 Issue，并参与月榜或季报整理。

身份不是永久头衔，也不由提交数量单独决定。项目更看重长期可信、愿意校验和能够帮助他人的贡献。

## 维护节奏

- **持续进行**：Issue 分类、PR 审核、去敏、事实与链接校验。
- **每月进行**：更新贡献记录，发布月度贡献者榜单，识别专题维护候选人。
- **每季度进行**：冻结报告样本，完成趋势分析、交叉验证、报告发布和下一季度路线调整。
- **每年进行**：更新招聘年份、归档过时信息、复盘贡献机制和专题边界。

## 隐私与内容边界

任何共创内容都必须尊重原创、隐私和保密边界。不要提交内部题库、业务数据、未授权聊天记录、个人联系方式或受保密协议约束的信息。招聘、薪资、模型能力和技术版本等时效信息，应附公开来源与核验日期；无法核验的内容必须明确标注为个人经验或待验证判断。
