# 待观察技术

这里保存值得持续跟踪、但尚未达到长期知识主干沉淀条件的技术信号。

进入观察区不代表技术没有价值，只表示当前证据不足以支持更高的长期学习优先级，或者它的机制、采用范围、成本和替代关系仍在变化。

## 最低记录字段

- 技术主题与所属方向；
- 发现日期、版本和来源；
- 它试图解决的问题；
- 当前看到的机制增量；
- 已经获得的产业、工程或岗位信号；
- 尚未确认的关键问题；
- 下一次复核条件和时间；
- 与现有教程、问答或路线的关系。

## 进入主线的条件

观察主题至少需要在机制解释、证据质量、迁移性和实际影响中形成足够积累，才可以提交正式的[技术价值判断卡](../技术价值判断卡模板.md)，并考虑升级为“产业验证中”“结构性增量”或“跨周期主干”。

当前暂无已经完成核验的观察主题。
