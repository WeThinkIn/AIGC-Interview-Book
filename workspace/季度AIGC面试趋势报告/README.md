# 季度 AIGC 面试趋势报告

季度报告的目标，是把分散的面经、公司题库、公开岗位 JD 和技术更新，转化为对学习与求职真正有用的岗位信号。报告关注可交叉验证的变化，不把单次面试经历放大成行业结论。

## 报告样本

报告可以使用以下样本：

- 当季完成去敏、来源说明和岗位分类的真实面经；
- 时间范围明确、能够区分真实题与预测题的公司题库；
- 来自公司官方招聘渠道、带核验日期的公开 JD；
- 有官方文档、论文、源码、模型卡或版本记录支持的技术更新；
- 已获得投稿者许可、只用于聚合统计的非公开样本。

以下内容不能直接进入趋势结论：无法核验的传闻、重复转载、来源边界不清的题库、过期招聘信息、样本量不足却被外推到整个行业的个人判断。

## 分析框架

| 分析层 | 核心问题 | 主要产出 |
| --- | --- | --- |
| 岗位层 | 哪些岗位在增加、合并或重新定义？ | 岗位方向与技术栈地图 |
| 能力层 | 企业正在提高哪些能力要求？ | 能力变化与优先级 |
| 面试层 | 高频题、追问和系统设计如何变化？ | 高频考点与典型追问 |
| 技术层 | 哪些新技术已进入真实岗位？ | 技术成熟度与岗位影响 |
| 人群层 | 校招、社招、转岗应如何调整？ | 分人群学习与求职建议 |

## 证据等级

- **强信号**：多个独立面经样本、多个公司公开 JD 或一手技术资料共同支持。
- **中等信号**：至少两个独立来源支持，但岗位或时间覆盖仍有限。
- **弱信号**：单一样本、新出现的技术名词或尚未形成稳定要求的变化。
- **观察项**：有潜在影响，但当前证据不足，不能进入确定性结论。

每个核心结论都应标明证据等级、样本时间范围和主要来源。没有足够证据时，宁可保留为观察项，也不制造趋势。

## 季度流程

1. 季度结束后冻结样本时间窗口，并从贡献台账生成候选样本清单。
2. 去重同一面经的多次转载，核验公司、岗位、时间、技术版本与授权范围。
3. 按岗位方向、候选人类型、面试轮次和技术主题建立分类。
4. 对高频变化进行交叉验证，区分强信号、中等信号、弱信号和观察项。
5. 使用 [季度报告模板](季度AIGC面试趋势报告模板.md) 完成写作与复核。
6. 发布后把结论回流热门教程、路线图和面试题库，形成下一季度更新重点。
