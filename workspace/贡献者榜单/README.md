# 月度贡献者榜单

月度贡献者榜单用于识别真正提升知识库质量的人。它不是提交次数排行榜，也不鼓励拆分 PR、重复投稿或追逐表面活跃度。

## 榜单依据

候选贡献必须已经进入 [贡献记录](../贡献记录/README.md)，并从以下维度形成质量说明：

| 维度 | 关注重点 | 权重参考 |
| --- | --- | ---: |
| 准确性 | 事实、机制和答案是否正确，依据是否可靠 | 30% |
| 完整度 | 背景、边界、结构和必要字段是否完整 | 20% |
| 复用价值 | 是否能帮助同类学习者、章节或报告 | 20% |
| 时效性 | 是否补齐新岗位、新框架、新模型或失效信息 | 15% |
| 社区影响 | 是否促进校验、讨论、后续贡献或内容维护 | 15% |

权重用于统一判断尺度，不要求把每个人简化成一个绝对分数。月榜正文应解释入选贡献的具体价值，并公开对应成果链接。

## 月度身份

- **本月高质量贡献者**：当月形成准确、完整且具有明显复用价值的成果。
- **本月共创推动者**：在内容整理、事实校验、隐私处理或协作推进中发挥关键作用。
- **专题共建伙伴**：围绕同一岗位、公司或技术方向形成连续贡献。
- **新锐贡献者**：首次贡献即达到较高质量标准，具有继续共建潜力。

同一贡献者可以符合多个身份，但榜单应避免堆叠头衔。没有达到公开质量标准的月份可以只发布共创进展，不强行评选。

## 发布流程

1. 每月最后一个自然日冻结当月已采纳贡献。
2. 次月前 7 天完成贡献链接、署名、样本权限和质量说明核验。
3. 对存在争议的贡献进行复核，不公开隐私信息和未合并内容。
4. 使用 [月度贡献者榜单模板](月度贡献者榜单模板.md) 发布，并回写年度贡献记录。
5. 连续三个月形成专题贡献的人，可以进入方向维护者候选名单。
