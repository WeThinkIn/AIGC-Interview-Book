# 共创指南

《三年面试五年模拟》欢迎真实、准确、可复用的长期贡献。这个项目不只需要修正错别字，更需要学习路线、真实面经、公司题库、岗位变化和技术演进共同构成的 AIGC 求职知识网络。

## 从这里开始

1. 阅读 [社区共创工作区](README.md)，选择与你的贡献最匹配的方向。
2. 小范围建议或尚未整理完成的内容，可以通过 [Issue 模板选择器](https://github.com/WeThinkIn/AIGC-Interview-Book/issues/new/choose) 提交。
3. 已经形成完整文档或明确修复的内容，可以 Fork 仓库并发起 Pull Request。
4. 提交前按照 [共创提交规范](共创提交规范.md) 完成来源、隐私、链接和 Markdown 检查。

## 我们优先接受什么

- 来自真实面试和岗位实践、已经完成去敏的结构化经验；
- 能说明来源边界、时间范围和不确定性的公司题库；
- 有官方文档、论文、源码或实践证据支持的技术纠错；
- 能复用现有章节链接，并包含学习输出和验收标准的路线图；
- 带有官方入口、截止时间和核验日期的招聘更新；
- 能解释机制、适用边界、证据边界及章节影响的模型、框架、算法、评测、部署或工程实践更新。

## 我们不会合并什么

- 受保密协议约束的面试题、业务数据、内部文档或未授权信息；
- 无法说明来源、把传闻写成事实或已经明显过时的招聘信息；
- 只有链接、模型名称或宣传语，没有判断和整理价值的内容；
- 大段复制第三方文章、题库或其他仓库，且没有明确授权；
- 为扩大改动量而重写原有问答、删除稳定锚点或进行无关重构。

## 署名与长期记录

被合并的贡献会保留 GitHub 提交和 PR 记录，并进入 [贡献记录台账](贡献记录/README.md) 的整理范围。高质量贡献还会进入 [月度贡献者榜单](贡献者榜单/README.md) 与 [季度 AIGC 面试趋势报告](季度AIGC面试趋势报告/README.md)。持续贡献者可逐步成为专题共建伙伴或方向维护者。

贡献者对其提交内容保留应有的署名权，同时同意项目在保留贡献记录的前提下，为保证准确性、一致性和隐私安全进行编辑、归档、去敏与勘误。
