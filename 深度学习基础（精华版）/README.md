主要内容简介：

01_机器学习基础：本章系统梳理机器学习基础面试核心考点，讲解机器学习本质、经典学习方式及在AIGC时代的延续价值。完整覆盖机器学习全流程，包含数据处理、特征构建、模型训练、验证评估与部署迭代闭环。详细解析损失函数、目标函数与奖励函数的作用，涵盖传统任务、多模态、AIGC生成与大模型对齐的各类损失设计思路。同时介绍梯度下降、反向传播与主流优化器的原理，阐释学习率、权重衰减等训练稳控策略。最后讲解模型融合与集成学习原理，拓展至AIGC与AI Agent的多模型协同、工具融合及工程落地风险，夯实AIGC算法必备的机器学习底层理论。

02_深度学习基础：本章梳理深度学习基础核心面试考点，对比深度学习与机器学习的核心差异，讲解深度学习处理非线性问题的核心机制。系统介绍神经网络底层原理，涵盖单层感知机缺陷、多层网络的拟合优势、神经元结构与前向传播流程。同时详解反向传播算法、计算图机制以及批次训练完整流程，区分模型表达、拟合与泛化能力，并归纳判别式与生成式模型、主流训练范式、自监督学习及各类网络架构的特点与适用场景，为深度学习入门打下理论基础。

03_深度学习网络架构：本章聚焦深度学习网络架构，汇总 AIGC 面试高频考点。从权重初始化、卷积、归一化、激活函数等基础组件展开，解析 ResNet、U-Net 经典网络；重点讲解 Transformer、自注意力、位置编码与推理优化，同步介绍 MoE、多模态、GNN 等前沿方向，打通传统深度学习、大模型与扩散模型知识脉络。

04_模型训练与优化：本章围绕深度学习模型训练体系，系统梳理 AIGC 算法工程师面试中的高频经典问题，按“数据—正则化—优化—训练实操—稳定性—进阶范式—评估”的完整链路展开。内容从数据标注、噪声标签、数据增强、清洗与长尾处理切入，讲清 L1/L2、Dropout、早停、标签平滑、权重衰减与 AdamW 解耦等正则手段；剖析学习率衰减与 warmup 调度、SGD 到 AdamW 的优化器脉络与选型；覆盖数据集划分、Batch Size、超参调优等训练实操，以及梯度裁剪/累积、混合精度、EMA、权重初始化、归一化层对比、激活函数选型、分布式并行与 ZeRO/FSDP 等稳定性技术；再延伸到迁移学习、预训练+微调、对比学习、参数高效微调 PEFT 等进阶范式，最后落到交叉验证、精确率/召回率/F1、ROC/AUC、偏差-方差与 AIGC 生成评估。
