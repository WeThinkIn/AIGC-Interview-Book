<h1 id="q-001">1.工业机器学习任务如何从业务目标转成可训练的问题？</h1>

<h2 id="q-002">面试问题：什么是质量软测量，它与普通回归预测有什么区别？</h2>

**难度评分：⭐⭐⭐ (3/5)  |  考察频率：⭐⭐⭐⭐ (4/5)**

质量软测量（Soft Sensor）是用容易连续采集的过程变量，估计难以在线、频繁或低成本测量的质量变量。输入可以是温度、压力、流量、功率、阀位、原料特征和设备状态，输出可以是纯度、杂质含量、强度或合格概率。

它与普通回归的区别不在算法名称，而在问题约束：

1. **标签滞后。** 质量标签通常来自抽样和实验室分析，结果返回时过程已经向前运行；模型必须根据采样时刻而不是结果录入时刻建立样本。
2. **过程动态。** 当前质量由历史窗口、物料停留时间和设备状态共同决定，不能只使用同一时刻的静态特征。
3. **标签稀疏且噪声高。** 过程信号可能秒级采集，质量标签却按批次或班次产生，必须处理混合样本、复测差和检出限。
4. **工况依赖。** 启停、稳态、切换、维护和异常状态的映射关系不同，通常需要工况识别或分层模型。
5. **输出要能拒答。** 当输入超出训练分布、关键点位失效或区间过宽时，正确行为是提示需要复核，而不是给出一个看似精确的数值。

一个可上线的软测量输出至少包括点估计、预测区间、合格/超限概率、工况、数据质量、模型版本和有效期。只给一个回归值，无法支撑高风险的过程决策。

**本质判断：**软测量不是把化验结果换成一个回归模型，而是把滞后的质量测量变成带时间对齐、工况判断和可信度管理的在线状态估计。

<h2 id="q-003">面试问题：工业时序数据为什么不能直接随机切分，如何避免时间泄漏？</h2>

**难度评分：⭐⭐⭐⭐ (4/5)  |  考察频率：⭐⭐⭐⭐⭐ (5/5)**

随机切分默认样本独立同分布，但工业过程通常存在自相关、批次相关、设备老化和操作反馈。随机切分会把同一批次相邻时刻，甚至未来信息同时放入训练集和测试集，得到一个无法代表上线外推能力的高分。

正确做法是按时间和业务边界切分：

```
较早连续时间窗：训练集
中间连续时间窗：验证集
最新连续时间窗：盲测集
上线以后：滚动前向验证
```

对于批式生产，应以完整批次为切分单位，不能把一个批次的前半段放到训练集、后半段放到测试集。对于连续生产，应增加留一原料批次、留一配方、维护前后和跨季节测试。

最常见的泄漏来源包括：

- 用化验结果返回时间之后才产生的字段构造预测时刻特征；
- 对全量数据先标准化、插值或降维，再切分训练和测试；
- 用未来窗口统计量填充当前缺失值；
- 把最终混合质量当作过程瞬时质量标签；
- 在滑动窗口中跨越训练/测试边界；
- 根据全数据挑选阈值、特征或异常样本后再报告测试结果。

每一次特征生成都应带有 available_time，训练样本只能引用可用时间不晚于预测时刻的变量。验证报告要同时给出总体指标、最差工况指标和最新时间窗指标。

<h2 id="q-004">面试问题：工业过程中的批次、停留时间和化验延迟应该如何建模？</h2>

**难度评分：⭐⭐⭐⭐⭐ (5/5)  |  考察频率：⭐⭐⭐ (3/5)**

工业质量标签对应的往往不是某一个瞬间，而是一段经过设备、管线、循环和储罐混合后的物料窗口。把标签简单向前平移一个固定时间，只有在流量和设备状态稳定时才勉强成立。

推荐建立“物料窗口/批次谱系”对象，记录来源批次、目标批次、流量或库存权重、开始/结束时间、设备、切换事件和关联可信度。一个混合样本的质量可以写成：

```math
y_j^{lab} \approx \sum_{t\in W_j} w_{j,t}y^{out}(t)+\epsilon_j,
\qquad \sum_{t\in W_j}w_{j,t}=1
```

$`W_j`$ 是样品对应的物料时间窗口，$`w_{j,t}`$ 由流量、库存、设备容积、回流和混合规则确定。若停留时间不确定，应对多个候选延迟做灵敏度分析，并把延迟不确定性传递给预测区间。

时间字段应严格区分过程事件时间、物料经过工序的时间、样品采集时间、实验室收到时间和结果可用时间。若生产存在合批、拆批、循环或多罐混合，谱系必须允许多对多关系，不能强行简化为一对一映射。

<h1 id="q-005">2.工业过程质量预测需要哪些核心机器学习算法？</h1>

<h2 id="q-006">面试问题：PLS、正则化回归和梯度提升树如何选择？</h2>

**难度评分：⭐⭐⭐⭐ (4/5)  |  考察频率：⭐⭐⭐⭐⭐ (5/5)**

这三类模型不是互相替代的算法排行榜，而是对应三种数据和交付约束。

<div align="center">

| 方法 | 更适合的条件 | 主要优势 | 主要风险 |
|---|---|---|---|
| PLS | 高维、强共线、样本相对较少的过程变量 | 潜变量压缩共线信息，解释性和稳定性较好 | 对强非线性和工况混合有限 |
| Ridge/Lasso/Elastic Net | 需要稳定基线、变量筛选或稀疏解释 | 训练快，正则化明确，便于部署和审计 | 需要处理非线性、滞后和尺度 |
| LightGBM/XGBoost/CatBoost | 非线性、阈值效应和变量交互明显 | 对表格特征强，能处理复杂交互 | 外推能力有限，容易学习数据捷径 |

</div>

PLS 的核心是寻找同时解释输入 $X$ 和目标 $Y$ 的潜变量，而不是只最大化输入方差。正则化回归通过参数惩罚控制模型复杂度：

```math
\min_{\beta}\;\frac{1}{n}\lVert y-X\beta\rVert_2^2+\lambda_1\lVert\beta\rVert_1+\lambda_2\lVert\beta\rVert_2^2
```

当输入变量具有明确物理意义、样本量有限且需要解释时，PLS 或 Elastic Net 往往是可靠起点。梯度提升树适合捕捉非线性，但必须通过时间外推、单调性或物理边界检查，避免把偶然故障编码成规律。

<h2 id="q-007">面试问题：AR/ARIMA、状态空间模型和深度时序模型有什么区别？</h2>

**难度评分：⭐⭐⭐⭐ (4/5)  |  考察频率：⭐⭐⭐⭐ (4/5)**

AR 模型把当前值表示成历史值的函数：

```math
y_t=c+\sum_{i=1}^{p}\phi_i y_{t-i}+\epsilon_t
```

ARIMA 通过差分处理趋势和非平稳性，适合单变量或少量变量、动态相对稳定的场景。

状态空间模型把过程拆成不可直接观测的状态和可观测输出：

```math
z_{t+1}=F_tz_t+B_tu_t+w_t
\qquad
y_t=H_tz_t+v_t
```

它适合处理传感器噪声、缺失观测、慢变量和多源测量。深度时序模型（TCN、TFT、N-HiTS 等）通过卷积、注意力或多尺度结构学习长窗口、非线性和多变量交互，但训练、校准和外推风险更高。

选择逻辑是：数据少且动态稳定时用 AR/ARIMA；需要隐状态和递推估计时用状态空间/Kalman/MHE；数据量足够且非线性明显时再评估深度模型；过程有物料或能量约束时优先灰箱或混合模型。

<h2 id="q-008">面试问题：如何用 Kalman Filter、MHE 或隐马尔可夫模型估计不可直接观测的过程状态？</h2>

**难度评分：⭐⭐⭐⭐⭐ (5/5)  |  考察频率：⭐⭐⭐ (3/5)**

反应充分度、设备效率、污染物累积或容器内平均质量等变量无法直接在线测量时，应建模为隐状态，而不是当作普通缺失值。

- **Kalman Filter：** 在线性、高斯条件下递推估计状态。
- **扩展/无迹 Kalman Filter：** 用局部线性化或 sigma 点近似处理非线性。
- **粒子滤波：** 用带权样本表示非高斯、多峰后验。
- **MHE：** 在滑动窗口内同时利用观测、模型、约束和噪声代价优化状态。
- **HMM：** 用离散状态、转移概率和观测概率识别稳态、切换和异常工况，不等同于连续质量估计。

一个通用状态估计目标为：

```math
\min_{z_{t-L:t},w,v}\sum_{k=t-L}^{t}\lVert w_k\rVert_{Q^{-1}}^2+\lVert v_k\rVert_{R^{-1}}^2
```

MHE 的价值不只是更复杂的滤波，而是把多源传感器、质量样本和工艺边界放到同一窗口中。若只有最终质量标签而没有中间观测，多个工序状态可能不可辨识，此时应增加中间样本、衡算或专家约束，并扩大不确定性。

<h1 id="q-009">3.预测结果如何变成可信的预警和可执行的优化？</h1>

<h2 id="q-010">面试问题：多目标质量预测为什么需要多任务学习和联合概率建模？</h2>

**难度评分：⭐⭐⭐⭐ (4/5)  |  考察频率：⭐⭐⭐ (3/5)**

多个质量指标通常共享原料、工况和设备状态，但其机理、噪声和规格边界不同。多任务学习使用共享表示和任务独立输出头，既复用过程动态，又保留指标差异。

```
共享：工况、批次、历史窗口、设备状态
独立：每个指标的回归/分类头、损失权重、规格和校准
融合：联合超限事件、合格概率和风险等级
```

联合合格概率不能简单把边缘概率相乘，因为指标风险可能相关：

```math
P_{qualified}=P(y_1\in spec_1,\,y_2\in spec_2,\,\ldots,\,y_m\in spec_m)
```

可使用多输出概率模型、协方差结构、copula、集成采样或直接训练联合事件分类器。训练时要处理标签频率不一致、检出限、缺失标签和类别不平衡。

<h2 id="q-011">面试问题：分位数回归、预测区间和共形预测分别解决什么问题？</h2>

**难度评分：⭐⭐⭐⭐ (4/5)  |  考察频率：⭐⭐⭐⭐ (4/5)**

点预测回答最可能是多少，工业决策更关心最坏情况下会不会越过规格。

1. **分位数回归：** 直接学习 $`q_{\alpha}(x)`$，例如 P10、P50、P90。Pinball loss 为：

```math
L_{\alpha}(y,\hat q_{\alpha})=
\begin{cases}
\alpha(y-\hat q_{\alpha}),&y\ge\hat q_{\alpha}\\
(1-\alpha)(\hat q_{\alpha}-y),&y<\hat q_{\alpha}
\end{cases}
```

2. **预测区间：** 给出覆盖未来真实值的上下界，必须同时评价覆盖率和区间宽度。
3. **共形预测：** 在校准集上利用残差或非一致性分数构造有限样本覆盖保证，可以包裹 PLS、树模型或深度模型。

预测区间和概率校准不是一回事：前者关注数值覆盖，后者关注报出概率与真实频率是否一致。遇到新工况、传感器漂移或区间过宽时，应扩大区间或拒答，而不是强行给出窄区间。

<h2 id="q-012">面试问题：工业异常检测与分布外检测有哪些常用算法？</h2>

**难度评分：⭐⭐⭐⭐ (4/5)  |  考察频率：⭐⭐⭐⭐ (4/5)**

异常检测寻找当前分布中的少见或不符合过程规律的样本，OOD 检测判断输入是否离开训练分布。两者相关但不等价：训练集里的真实故障可能是异常却不一定是 OOD，新工况可能很平稳却仍是 OOD。

<div align="center">

| 方法 | 适用场景 | 典型信号 |
|---|---|---|
| 工艺规则、控制图、EWMA | 有明确上下限和稳态基线 | 越限、趋势、累计偏移 |
| Hampel、MAD、稳健 Z 分数 | 尖峰、冻结和局部离群 | 局部鲁棒距离 |
| Isolation Forest | 中高维表格特征、标签少 | 隔离路径长度 |
| One-Class SVM | 样本量适中、边界较清晰 | 到支持边界的距离 |
| PCA/自编码器残差 | 高维相关传感器 | 重构误差或子空间残差 |
| 距离、密度和集成分歧 | OOD 和组合新颖性 | Mahalanobis 距离、模型方差 |

</div>

真实异常样本应保留并打标签，不能因为偏离均值就自动删除。异常或 OOD 触发时，系统应停止参数建议、扩大区间、提示人工取样或切换到保守规则；检测阈值要按工况校准。

<h2 id="q-013">面试问题：贝叶斯优化、约束优化和模型预测控制如何协同？</h2>

**难度评分：⭐⭐⭐⭐⭐ (5/5)  |  考察频率：⭐⭐⭐ (3/5)**

三者解决的问题不同：

- **贝叶斯优化：** 在试验昂贵、目标黑箱且样本少时，用代理模型和采集函数选择下一组离线试验点；
- **约束优化：** 在给定模型、目标和可行域内寻找满足边界的决策；
- **MPC：** 在每个控制周期预测未来窗口，求解动作轨迹，只执行第一步，然后滚动重算。

推荐组合为：

```
历史数据/受控试验
→ 学习动作响应代理模型
→ 鲁棒约束优化或经济型 MPC
→ 独立策略门复核
→ 操作员确认/现有控制系统执行
```

目标可同时惩罚质量超限风险、波动、能耗和动作幅度：

```math
\min_{u_{t:t+H}}\;w_qRisk_{offspec}+w_vVariance+w_cCost+w_u\lVert\Delta u\rVert_2^2
```

约束包括设备边界、投料和流量上下限、动作变化率、最短保持时间、产能、下游接收能力、联锁和工况白名单。遗传算法或粒子群可做离线对照，但不应绕过物理约束直接写入生产回路。

<h1 id="q-014">4.模型怎样评估、监控并安全迭代？</h1>

<h2 id="q-015">面试问题：为什么质量预测模型不能直接生成控制动作，如何建立动作响应模型？</h2>

**难度评分：⭐⭐⭐⭐⭐ (5/5)  |  考察频率：⭐⭐⭐⭐ (4/5)**

质量预测模型学习的是 $P(y\mid x)$ 或 $E[y\mid x]$，回答观察到这些变量时质量可能怎样，并不自动回答主动修改变量后质量会怎样。历史数据还会出现反向因果：操作员先看到质量恶化，再调节参数，模型可能错误地把调节动作和坏结果绑定。

动作响应模型要估计干预后的结果，例如 $P(y\mid do(u=\tilde u),x)$。可靠的建立顺序是：

1. 从历史设定值阶跃、自然扰动和操作记录中识别变量方向、滞后、增益和有效范围；
2. 用物料/能量衡算、设备机理和工艺人员审查结果排除违反基本规律的响应；
3. 对无法识别的变量，在批准安全窗口内设计小幅、分阶段、可回退的受控试验；
4. 在未参与辨识的时间窗和压力场景中验证动作后果；
5. 优化时对响应不确定性做鲁棒处理，使用最坏场景或风险约束而非平均值。

可使用状态空间/灰箱模型、局部系统辨识、因果回归、双重机器学习、因果森林或结构化代理模型，但算法名称不是可信度来源。可信度来自动作可辨识、时间顺序正确、试验边界清晰、结果可重复和安全策略独立。

<h2 id="q-016">面试问题：工业时序预测应该使用哪些评估指标和验证策略？</h2>

**难度评分：⭐⭐⭐⭐ (4/5)  |  考察频率：⭐⭐⭐⭐⭐ (5/5)**

工业模型评价要从平均误差升级为能否提前、可信、可执行。

<div align="center">

| 层级 | 代表指标 | 关注点 |
|---|---|---|
| 数值精度 | MAE、RMSE、nMAE、规格带宽归一化误差 | 点预测偏差和极端误差 |
| 事件识别 | Recall、Precision、F1、PR-AUC、提前量 | 超限和风险是否及时识别 |
| 概率质量 | 区间覆盖率、区间宽度、Brier Score、ECE | 置信度是否可信 |
| 工程可用 | OOD 拒绝率、建议可行率、求解时延、撤销率 | 是否应该上线和是否会误导 |

</div>

验证必须采用时间外推和业务分层：最新连续窗口、留一批次/配方、维护前后、切换工况和质量边缘样本。连续预测还要评价多个预测步长，避免模型只在短期滞后上有效。

预警任务要先冻结事件定义：持续多久算一次事件、提前多久算有效、相邻告警如何合并、误报和漏报成本分别是多少。业务试点应采用匹配工况、交叉时段或因果校正比较质量波动、合格率、能耗和返工。

<h2 id="q-017">面试问题：Champion/Challenger、漂移监控和拒绝策略如何组成可靠的上线闭环？</h2>

**难度评分：⭐⭐⭐⭐⭐ (5/5)  |  考察频率：⭐⭐⭐⭐ (4/5)**

生产模型不是训练完成后永久不变的文件，而是需要持续观察、验证和回滚的系统：

```
新数据进入候选集
→ 数据质量、标签和谱系检查
→ Challenger 训练
→ 时间盲测与工况分层评估
→ 历史回放、故障注入和在线影子运行
→ 与 Champion 对比
→ 审批、灰度发布
→ 漂移监控、效果回写和一键回滚
```

监控分为五类：

1. **数据漂移：** 特征分布、缺失率、冻结率、单位、时延和质量码变化；
2. **概念漂移：** 新化验返回后比较预测残差、校准和工况分层性能；
3. **工况覆盖：** 新原料、新配方、新负荷、维护后状态和未知组合比例；
4. **优化健康：** 求解成功率、可行率、时延、动作幅度、执行后响应和撤销率；
5. **业务结果：** 规格边缘样本、不合格率、波动、能耗和操作员采纳/拒绝原因。

以下情况应自动进入 ABSTAIN/SAFE-HOLD：关键点位无效、数据过期、工况未知、OOD 分数过高、概率区间过宽、动作响应超出辨识范围、优化不可行或联锁异常。自动更新只能更新候选模型和监控统计，不能未经验证覆盖生产 Champion。

**本质判断：**模型上线的终点不是部署成功，而是预测、拒答、审批、执行、反馈和回滚都能被审计。
