# 《三年面试五年模拟》之 AI Agent 基础知识高频考点

本板块包含 **10 篇章节、294 道面试子问题**，面向AI Agent算法、应用工程与平台架构面试。内容从任务与工具的基本关系，展开到执行状态、协议、记忆、评测、企业落地和知识检索。每个答案说明机制、具体例子、工程取舍与适用边界，便于理解后结合真实项目作答。

技术与产品信息核对截至 **2026-11-25**。正文区分通用机制、具体版本与论文实验；新研究用于解释可迁移的问题，不将单篇论文结果当作生产保证。

## 建议阅读顺序

第一次系统学习，可按 **01 → 03 → 04 → 05 → 10 → 06 → 08 → 02 → 07 → 09** 阅读：先建立任务与执行的地图，再掌握编排、接口和证据，最后进入场景工程与长期运行。

准备具体岗位时，可以选择更集中的路线：

- **Agent应用工程**：01、03、04、05、10、06。重点讲清任务状态、工具调用、证据质量和失败恢复。
- **编码Agent与开发工具**：01、02、03、04、06、08。重点区分工作区隔离、执行环境、测试证据和真实业务副作用。
- **企业平台与架构**：01、04、06、07、08、09。重点说明身份、租户、状态、发布、可观测性和迁移资产。
- **记忆、自进化与训练**：05、06、08、09。先建立独立评测，再讨论经验怎样改变流程或模型参数。
- **RAG与知识工程**：05、10、06。重点验证解析、切分、检索、权限、引用和无答案处理。

答题时先给出核心判断，再解释机制与例子，最后说明失败条件与取舍。涉及“你在项目中怎么做”的问题，应使用自己的真实数据；正文中的教学参数和假设算例不能当作项目实测结果。

难度与考察频率采用编辑性分级，用于安排复习顺序，不代表基于统一面试样本统计得出的概率。
