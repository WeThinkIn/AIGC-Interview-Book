## 阅读路径

1. 先读基础篇中的张量、SVD、梯度、条件概率、统计估计、KL 与优化。每次遇到一个公式，先写清变量的维度、采样分布与单位。
2. 再读推导篇。重点复现被省略时最容易出错的步骤：归一化分母的导数、支撑集、时间权重、条件期望、全导数与损失归约。
3. 最后进入专题篇，判断一个新方法究竟改变了模型结构、训练目标、梯度估计还是数值求解。优先理解机制，再看具体版本的经验收益。

按方向选择时，大模型训练可重点连读优化、期望求导、对齐损失与 Muon；推理工程可连读注意力复杂度、KV Cache、MLA、投机解码与量化；生成方向可连读 VAE、DDPM、连续性方程、Flow Matching、最优传输与 MeanFlow；AI for Science 可从量纲、动力系统和初边值问题进入神经算子、对称性与形式化验证。

## 内容边界

基础篇负责概念、例子和适用条件；推导篇给出关键代数与概率步骤；专题篇讨论结构选择、复杂度和新方法的有效边界。相同主题在不同章节承担不同问题，深入部分通过链接连接。

本板块不替代完整的实分析、测度论或理论物理教材。物理内容聚焦与模型学习相关的量纲、耗散、守恒、随机过程和数值求解；生成模型中的“时间”“能量”等词，只有在明确方程与单位后才作物理解释。训练系统、模型部署与具体业务流程可继续参阅相邻板块。
