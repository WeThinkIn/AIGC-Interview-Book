# 《三年面试五年模拟》之计算机基础知识高频面试考点

模型能跑起来之后，很多问题会落到计算机系统上：为什么增加 worker 反而变慢，为什么本机能访问而容器不能，为什么请求超时后任务还在扣费，为什么数据库有事务却仍然出现业务不一致。理解这些问题，需要把进程、存储、协议和服务状态连起来。

本板块围绕 AI 算法与工程工作中常见的系统问题展开。每道问答先解释机制，再给出可分析的例子、工程取舍和适用边界。命令中的主机、路径和端口属于示例，使用时应结合自己的权限、环境与版本核对。

## 怎样把这些知识用起来

- **服务吞吐不足**：先区分 CPU、GPU、I/O、锁、队列和网络瓶颈，再讨论进程数、异步或批处理。操作系统章解释资源机制，工程章解释服务组织。
- **接口超时与重复执行**：先判断失败阶段和结果是否确定，再用 deadline、幂等键、任务状态与 Outbox 设计恢复。网络章负责调用语义，数据库章负责提交边界。
- **部署后行为不一致**：核对镜像与模型版本、依赖、驱动、运行身份、挂载和配置，避免只比较源代码。工程章提供交付与诊断路径。
- **代理打开仍访问失败**：分别确认接管入口、DNS、规则、节点传输和目标站连接。代理章深入这条路径，网络章提供基础诊断方法。

## 内容边界

操作系统章关注内核与进程看到的资源；工程章关注如何把程序组织为可运行、可恢复的服务。网络章讲协议与远程调用，代理章深入路径接管与信任；数据库章讲持久状态与一致性。涉及 Agent、模型推理或分布式训练时，例子用于解释系统机制，模型结构与具体算法由对应专题板块展开。

free-threading、PSI、NUMA 与页锁定内存、软件供应链证据、背压、QUIC、Outbox 与列式分析等内容，按可迁移的原理组织。框架版本会变化，资源所有权、提交边界、失败语义和观测方法仍值得反复掌握。

难度与考察频率采用 1—5 星的编辑评分，用于安排学习优先级；频率来自题目在通用技术面试中的适用程度判断，不代表已做统计抽样。资料核验日期为 **2026-11-26**，实现细节以章末官方资料和实际部署版本为准。
