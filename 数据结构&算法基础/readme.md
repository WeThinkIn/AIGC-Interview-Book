# 数据结构与算法基础

数据结构与算法决定数据怎样存、一次计算怎样少做无用工作，以及系统在规模增长时能否继续运行。本板块面向 AI 算法、推理部署、RAG 与 Agent 工程岗位，保留经典基础，再放进数据处理、检索、缓存和流式执行中解释。

共 **7 章、116 个问答**，围绕机制、例子、复杂度前提和失效边界展开。实现集中在 [codes](codes/README.md)，覆盖 Python、C++20 与 Java 21。

## 当前值得深入的工程机制

截至 2026-11-27，值得反复学习的变化集中在表示与预算管理：Swiss Tables 先筛元数据再读完整键，Roaring 按局部密度表示集合，前缀缓存精确管理共享状态，过滤 ANN 同时处理覆盖与硬条件，KLL 保存可合并的分布摘要，量化检索协调压缩、搜索宽度和精排。问答解释可迁移的机制，不以模型名称或单次加速数字代替原理。

## 内容边界

本板块负责容器、算法不变量、复杂度与局部实现。操作系统、网络、数据库事务及并发运行时见[计算机基础](../计算机基础/readme.md)；模型数学、训练目标与完整推理框架由对应专题展开。RAG、KV Cache、Agent 场景用于说明算法条件，不将教学模板视为完整生产框架。

难度和频率是用于学习排序的编辑判断，不是招聘市场统计。性能结论应结合输入、输出语义与环境阅读。
