# LeetCode Hot 100 学习路线

这份入口按能力组织代表题与本板块讲解，帮助把刷题转成可复用的算法判断。完整题单可在 [LeetCode Hot 100](https://leetcode.cn/studyplan/top-100-liked/) 查阅。本文提供练习路线和原理链接，各题的平台完整解答与提交记录需要在练习中完成。

每题先写输入与输出契约，手推正常样例和最小反例，再解释不变量与复杂度，最后编码并与小规模暴力参考比较。做完后改变一个条件，例如允许重复、加入负数、把树改成图，检查原方法何时失效。
