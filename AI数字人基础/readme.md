# 《三年面试五年模拟》之 AI 数字人基础知识高频考点

数字人需要把人物身份、运动、声音和交互状态放到同一条时间线上。学习这个方向，既要解释生成模型怎样工作，也要说明角色为什么会漂移、口型为什么会错位，以及模型能否在目标设备上持续运行。

本板块面向数字人、人物视频生成、3D Avatar 与实时多模态交互方向的算法和工程面试。内容更新至 **2026-11-23**，共 **6 篇章节、159 道面试子问题**。

## 内容边界

总览章负责快速判断任务与系统约束，具体方法在专题章展开。02 负责身体与角色控制，03 负责音频与时间，04 负责身份编辑与服装，05 负责几何及渲染，06 负责生成机制和技术取舍。跨章重合处通过链接衔接。

通用视频生成、扩散训练的完整推导，以及 ASR、TTS 和语言模型本身的原理，应结合相应基础板块学习。这里重点讨论它们进入数字人系统后新增的身份、运动、音画与交互约束。

近期论文作为可检验的机制案例，不直接等同于主流产品已经采用。各章参考资料提供原论文或官方项目入口；速度、分辨率、许可和可用模型应按实际部署版本确认。
