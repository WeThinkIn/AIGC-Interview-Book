# 核心教程：从目标出发，找到你的 AIGC 学习路线

《三年面试五年模拟》已经覆盖大模型、AI Agent、多模态、图像视频生成、模型部署、编程与求职等知识板块。**核心教程不重复生产一套知识，而是把已有高质量问答组织成可执行的学习路线**：先确定目标岗位与当前基础，再按阶段完成阅读、表达、实践和复盘。

## 这套路线如何使用

每个阶段都遵循同一个学习闭环：

1. **先读地图**：知道这一阶段解决什么问题，以及它和目标岗位的关系。
2. **再读原题**：通过教程中的链接直达原有问答，不脱离完整上下文孤立背诵。
3. **主动复述**：每道核心题按“定义 -> 机制 -> 对比 -> 工程取舍 -> 一句话收束”口述。
4. **形成产出**：完成代码、架构图、评测报告、项目复盘或岗位分析，而不只留下阅读记录。
5. **通过验收**：能脱稿说明、能处理追问、能把知识放回真实系统，才算完成。

## 共同学习原则

- **路线不是课程表**：它给出优先级，而不是要求把仓库从头到尾读完。
- **主线只保留一条**：先围绕一个目标岗位建立最小闭环，再拓展多模态、部署或 Agent 等第二方向。
- **项目必须可验证**：至少具备数据来源、基线、评测指标、失败案例和改进记录。
- **面试表达必须来自理解**：不要只记结论，要能够解释为什么这样设计，以及不用另一种方法的原因。
- **每周必须有外显产出**：代码仓库、技术文章、项目文档、口述录音或模拟面试记录至少完成一种。

## 路线与知识板块的关系

核心教程是“用户目标层”，原有模块是“知识资产层”：

- 不改动、不复制原有问答正文。
- 路线页通过稳定锚点组合不同模块中的核心问题。
- 同一道题可以服务不同路线，但每条路线赋予它不同的学习目标和验收方式。
- 原有章节持续更新时，路线仍保持清晰的岗位导向和阅读顺序。
