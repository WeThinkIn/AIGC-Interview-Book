# 《三年面试五年模拟》之经典模型知识高频考点

这个板块围绕模型怎样表示信息、接受监督、形成预测，以及怎样进入实际系统展开。CNN、Transformer、度量学习、潜变量与强化学习的许多基本问题，仍然出现在今天的视觉基础模型、多模态模型、文档解析和生成系统中。

全板块共 **10 章、270 道问答**，适合计算机视觉、AIGC、多模态、NLP / LLM 和算法工程岗位。每题给出难度与考察频率，回答侧重机制、例子、工程取舍和适用条件。阅读时可先尝试解释“输入是什么、监督从哪里来、推理怎样执行、什么情况下会失败”，再补充具体模型的结构细节。

## 建议阅读顺序

- **视觉算法基础**：先读图像分类，再读目标检测和图像分割；把特征、监督、定位与评价串起来。随后按岗位补充 OCR、人脸或跟踪。
- **视频与身份检索**：先掌握检测，再读目标跟踪与 ReID；分清检测候选、连续轨迹和跨摄像头身份的职责。涉及脸部线索时补读人脸章节。
- **AIGC 与多模态**：先读视觉骨干和 VAE，再读自然语言处理中的图文接口与视觉 token；结合分割和跟踪理解编辑条件与时序证据。
- **模型对齐与 Agent**：先掌握序列建模，再读强化学习；重点追问奖励是否可靠、长期结果怎样归因，以及训练和部署能够获得哪些信息。

时间有限时，优先完成考察频率为 4—5 星的题目。进阶题的用途是建立判断条件，例如模型输出分布是否校准、局部特征是否真正对齐、复杂复核是否覆盖调用成本，而非记住更多论文名称。

## 内容边界

分类章节负责视觉表征与骨干；检测和分割章节分别负责目标级与像素级预测。相同骨干在多个任务中出现时，专章只展开该任务特有的监督、匹配与后处理，避免重复基础结构。

跟踪章节负责时间连续性、轨迹状态和关联；ReID 章节负责外观表示与图库检索。人脸章节进一步讨论脸部质量、验证和身份模板。外观相似、轨迹连续和登记身份一致是不同证据，应结合系统条件使用。

VAE 章节讲压缩、重构与潜变量；分类章节中的 DiT 等例子用于说明骨干结构的迁移。完整的图像生成训练与采样问题，可继续阅读 [AIGC 图像创作与 AI 绘画基础](../AIGC图像创作&AI绘画基础/README.md)。自然语言处理章节讲模型与表示接口，不承担完整的 Agent 运行框架教程。

强化学习章节同时保留迁移学习、LoRA 等高频训练问题，但区分参数更新方式与奖励驱动的优化目标。人脸生成的业务选型、交付与运营可结合 [AI 业务场景问题](../AI行业职业生涯开放性问题/AI业务场景问题.md) 阅读。

## 怎样使用近期研究

截至 **2026-11-26**，新增与补充内容重点关注可迁移的问题：视觉基础模型的下游验证、概念与示例提示、表示自编码器、边界框分布精修、离线语义监督、文档信息压缩、轨迹记忆、局部身份线索和按需复核。

近期方法放在相应问题中解释，并保留训练数据、评价协议、计算成本与公开实现的限制。模型较新、参数较多或某项指标较高，都需要进一步落实到“改进来自哪里、代价是什么、能否适用于当前任务”。各章参考资料提供原论文或官方实现，配图旁标注来源；公式与代码用于直接说明机制。
