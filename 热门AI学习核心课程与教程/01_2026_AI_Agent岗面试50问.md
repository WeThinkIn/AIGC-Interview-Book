## 先抓主干

这条路线不是为了把 50 个问题机械背完，而是先建立一条稳定的 Agent 认知链：**Agent 是什么 -> 怎么行动 -> 怎么用工具 -> 怎么记住状态 -> 怎么评测 -> 怎么上线**。

## 推荐顺序

1. 先看 Agent 本体与运行循环，避免把 Chatbot、Workflow 和 Agent 混为一谈。
2. 再看 Tool Use、MCP/A2A 和设计模式，理解系统如何从“会说”走向“会做”。
3. 最后补齐 Memory、安全、评测和平台层，完成面试里最容易追问的工程闭环。
