# AI Agent 工程岗面试路线

> 路线定位：面向 Agent 工程、编排平台、MCP/A2A、编码 Agent 和 AgentOps 岗位。重点不是“会接 API”，而是“会设计可控的执行系统”。

[返回热门AI学习核心课程与教程总览](README.md) | [返回项目主页](../README.md)

## 先抓重点

工程岗最看重的不是某个框架，而是你是否知道：哪些步骤该交给模型，哪些必须交给代码，哪些要做权限、审计和回退。

## 推荐顺序

1. 先学 Agent 本体、工作流与设计模式。
2. 再学 MCP/A2A、Memory 和编码 Agent。
3. 最后补安全评测、Harness 和企业平台。
